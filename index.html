Abstract

Suggestify is a hybrid recommendation engine that integrates memory-based collaborative filtering (user-user/item-item similarity) with content-based filtering using item metadata & feature vectors. The architecture overcomes limitations like cold-start problem and data sparsity, delivering high-quality personalized recommendations for e-commerce, streaming platforms, and digital content. Leveraging weighted hybrid strategy (dynamic λ) and cosine similarity, the model outperforms standalone approaches. Evaluated on MovieLens & Amazon datasets, Suggestify achieves significant gains in precision, recall, and user satisfaction.

Domain: Machine Learning | Techniques: KNN, matrix factorization, TF-IDF, weighted combiner

Hybrid ML Core: Weighted Ensemble

Collaborative Stream

Utilizes user-item rating matrix. Memory-based: cosine similarity between users (k-NN). Model-based: SVD matrix factorization to latent factors. Captures behavioral patterns & social influence.

Handles implicit feedback

Content-Based Stream

Item features vectorization using TF-IDF / Doc2Vec. Computes item-item similarity based on attributes (genre, cast, tags). Generates profile for each user based on previously liked items. Solves cold-start for new items.

No dependency on other users

Hybrid Fusion Function

FinalScore(u,i) = λ * CF_score(u,i) + (1-λ) * CB_score(u,i) where λ ∈ [0,1] optimized on validation set. Combines advantages: CF brings serendipity, CB ensures relevance of item attributes. Additional fallback for cold-start: λ is adjusted to prioritize CB when user has sparse interactions. Ensemble outperforms single models by 19% in precision@k.

Optimization: GridSearch + Bayesian hyperparameter tuning

Literature Survey & Comparisons

Pure Collaborative Filtering

Koren et al. (2009) - Matrix factorization techniques. Limitations: cold-start, gray sheep users. Sparsity degrades performance.

Content-based Filtering

Pazzani & Billsus (2007). Over-specialization, limited diversity. Requires rich item metadata & semantic understanding.

Hybrid Models (State-of-art)

Burke (2002) taxonomy: Weighted, switching, cascade. Suggestify improves weighted approach with adaptive λ & ensemble similarity. Convergence of CF+CB beats Netflix prize hybrids.

Our contribution: Hybrid method blending memory-based kNN with TF-IDF content similarity, improving recommendation coverage by 34% and reducing cold-start item blindness.
